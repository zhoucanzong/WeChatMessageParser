# 微信本地聊天归档

目标是可核验的个人聊天档案。由 Agent 判断用户意图、目标会话、取钥授权、
解析可信度和交付范围；脚本只负责确定性的读取、解码、渲染与检查。

## 从当前状态开始

- 明确用户指定的数据源、联系人/群及时间范围；已有上下文足够时直接推进。
- 用户已经提供归一化 JSON 或已解密记录时，直接从解析/渲染阶段继续，不重新取钥。
- 在技能目录之外选择私有工作目录。密钥、数据库副本、正文和媒体只能写入
  该目录，不作为技能资源、测试数据或分享包的一部分。
- 检查本机平台、微信版本、账号目录和是否有可复用的密钥。多个账号或同名
  联系人时精确消歧，不默认取第一个。
- 遇到 `Backup/.../ChatPackage`、`RMFH` 文件，先读
  [数据源区别](references/formats.md#rmfh-手机备份)。不能把 SQLCipher 的
  成功读取解释成手机备份已解密。

## 读取本地数据库

按需读 [Mac 读取与初始化](references/macos.md)。

1. 优先用已有的本账号密钥，在独立 DB/WAL/SHM 副本上验证。
   只读打开、第一页 HMAC、SQLite 完整性检查分别记录；成功验收才读正文。
2. 无密钥时，先完成只读检查和合成程序测试。临时副本取钥涉及退出微信、
   重签副本及可能重新登录，需确认当前会话已授权这些影响；已经授权则不重复问。
   技能被选中本身不构成取钥、退出应用或改变系统设置的授权。
3. 脚本拒绝在原微信仍运行时启动副本。正常退出失败时核查进程与对话框，
   不用 `killall`，也不自动强杀原微信。扫码和手机确认由用户完成。
4. 取钥只保存匹配所选数据库且通过 HMAC 的密钥。结束自己创建的子进程，
   恢复原版，核验原应用签名/哈希和临时进程状态。SIP 和原应用签名不变。
5. 用 `archive.py resolve` 精确匹配目标，然后 `archive.py export`。
   日期、账号、自身 ID 都是本次输入；不要从技能示例推定用户身份。

缺失个别辅助库密钥不等于所有聊天不可读；报告已验证的库和缺口，避免为
无关库重复打断微信。取钥方法受架构和客户端版本影响，失败保留诊断，
不移除认证检查“强行兼容”。

## 消息和媒体

按需读 [格式与媒体](references/formats.md)。

- 跨消息分库收集目标会话，记录选择范围的行数和实际导出行数。不要把
  联系人表行数当作好友数，或把分库行数之和当作已去重的消息数。
- 文字解压后保留原文。通话只解析状态和显示时长，不推测谁拒绝，不声称
  获得通话录音。小程序只提取卡片元数据，不自动访问链接。
- 图片经资源表按会话 + server ID 定位，再解码本地 DAT；语音经 VoiceInfo
  的同一组合唯一匹配，SILK 转 WAV。不通过昵称、文件大小或最近修改时间猜配。
- 明确区分原图/缩略图、音频解码/文字转写、视觉检查/哈希验证。
  哈希不一致或原始哈希缺失都要记录；图片能打开不等于完整性校验通过。
- 默认不运行语音识别。用户需要时可选择本机模型，下载模型不上传音频。
  机器输出必须标注；幻觉、字幕口号、重复或不确定内容不能写成用户原话。
- 缺失媒体、未支持表情、无法解析的 XML 保留对应消息和原因，不静默删除。

## 自包含交付

运行 `render_html.py`，再运行 `audit_html.py`。命令与数据格式见
[运行参数](references/commands.md)。

- HTML 只使用内嵌 JPEG/PNG/GIF/WebP、WAV/MP4 和内联样式，无远程字体、
  CDN、跟踪或执行脚本。正文必须 HTML 转义，原始 XML 凭据不得进入页面。
- 渲染器仅读取指定媒体根目录内的文件，拒绝路径越界和超过容量上限。
  大档案需明确调整上限或征得用户同意拆分，不悄悄遗漏附件。
- 校验消息条数、资源数量、可解码性和外部引用。若浏览器支持，打开检查
  页面及媒体；若策略禁止本地预览，不绕过，说明只完成静态/解码校验。
- 交付 HTML 与覆盖率摘要；按需要附 TXT/JSON。指出尚未还原的类型。
  用户未请求发布或分享时，只提供本地文件。

## 技能维护和分发

测试只使用临时生成的虚构联系人、随机密钥和人工媒体，不再次运行真实取钥。
`package_skill.py` 仅打包清单中的源码与文档，拒绝符号链接、额外文件和
明显身份/密钥字面量；维护者可从包外传入本地隐私标识文件做精确复检。
不把本次处理过的姓名、账号、聊天摘录、绝对用户路径或运行统计写回技能。

来源、许可与能力边界见 [参考与许可](references/sources.md)。
